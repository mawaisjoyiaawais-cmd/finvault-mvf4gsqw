# FinVault

Secure personal finance tracker with offline 4-digit PIN protection, income and expense logs, savings goal trackers, and monthly visual category reports.

## Screens
- **PinScreen** — Secure authentication gate verifying the 4-digit PIN before granting access to local financial records.
- **DashboardScreen** — Central overview displaying current net balance, monthly income versus expenses, and shortcut widgets.
- **AddTransactionScreen** — Form to record a new income or expense transaction into the local ledger.
- **TransactionHistoryScreen** — Comprehensive chronological feed of all recorded transactions with search and delete capabilities.
- **ReportsScreen** — Analytical summary providing category-wise spending breakdown and income-to-expense ratios for a chosen month.
- **SavingsGoalsScreen** — Manage financial targets and monitor progress toward custom savings milestones.
- **AddGoalScreen** — Creation form for establishing a new savings target.
- **SettingsScreen** — Preferences management for security, currency formatting, and local data maintenance.
